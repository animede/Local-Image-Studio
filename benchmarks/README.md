# Benchmark data

The files in this directory are generated by `scripts/benchmark_gpu.py`.
Markdown is intended for human review; JSON contains the same results in a
machine-readable form.

## Canonical comparison set

- `20260925-214049-nvidia-rtx-pro-5000-blackwell-fast`
- `20260925-214218-nvidia-rtx-pro-5000-blackwell-turbo`
- `20260925-215401-nvidia-rtx-pro-5000-blackwell-compatible`
- `20260925-215437-nvidia-rtx-pro-5000-blackwell-quality`
- `20260925-215540-nvidia-rtx-pro-5000-blackwell-minimum-vram`
- `20260925-215627-nvidia-rtx-pro-5000-blackwell-turbo-fp8`
- `20260925-215647-nvidia-rtx-pro-5000-blackwell-turbo-bf16`
- `20260925-215738-nvidia-rtx-pro-5000-blackwell-turbo-minimum-vram`

These reports were measured on GPU0 of the same RTX PRO 5000 Blackwell system.
Normal profiles use 40 steps; Viggle profiles use the official 6-step schedule.

Superseded exploratory, 2-step, split-run, and wrong-device measurements are
kept only in the locally ignored `archive/` directory. They are not part of the
public comparison set.
